# ✨ A Little Magic ✨

A single-file interactive birthday gift website — no frameworks, no build step, just one HTML file.

## 🎁 What's Inside

- 🔐 Phone-style lock screen with PIN keypad
- 🎆 Fireworks & confetti animations
- 🖼️ Flip-card memory gallery
- 🎂 Interactive birthday cake
- 💌 A heartfelt letter
- 🎙️ Embedded voice message player
- 🏆 A personalized award certificate
- 🌙 A grand finale ending

## 🛠️ Tech

Pure HTML + CSS + vanilla JS. All images & audio are embedded as base64 — the file is fully self-contained and works offline.
